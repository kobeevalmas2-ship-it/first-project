# Публикация сайта

Сайт состоит из статических HTML, CSS и JavaScript-файлов и не требует сборки.

## GitHub Pages

1. Откройте репозиторий на GitHub и перейдите в **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/ (root)**, затем нажмите **Save**.
4. После публикации откройте адрес сайта, который появится в разделе Pages.

Файлы сайта и изображения должны находиться в корне выбранной ветки. Ссылки между страницами относительные; товары загружаются по HTTPS с DummyJSON.

## Данные магазина

Каталог, категории, карточки товаров, отзывы и демонстрационное оформление заказа используют API [DummyJSON](https://dummyjson.com/docs/products). Корзина сохраняется только в localStorage браузера. DummyJSON — демонстрационный сервер: изменения и оформленные заказы на нём не сохраняются.
