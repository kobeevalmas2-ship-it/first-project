# Публикация сайта

Сайт состоит из статических HTML, CSS и JavaScript-файлов и не требует сборки.

## GitHub Pages

1. Откройте репозиторий на GitHub и перейдите в **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/ (root)**, затем нажмите **Save**.
4. После публикации откройте адрес сайта, который появится в разделе Pages.

Файлы сайта и изображения должны находиться в корне выбранной ветки. Ссылки между страницами относительные; товары загружаются по HTTPS с DummyJSON.

## Данные магазина

Каталог, категории, карточки товаров, отзывы и демонстрационное оформление заказа используют API [DummyJSON](https://dummyjson.com/docs/products). Корзина сохраняется только в localStorage браузера. DummyJSON — демонстрационный сервер: изменения и оформленные заказы на нём не сохраняются.

## CRUD товаров

В магазине доступны все четыре операции: создание кнопкой **Добавить товар**, просмотр карточки, редактирование кнопкой **Изменить** и удаление кнопкой **Удалить** с подтверждением. Можно менять название, описание, бренд, цену, скидку, остаток, категорию и изображение.

Изменения хранятся в `localStorage` под ключом `shop:products:v1` и применяются поверх каталога DummyJSON. Они сохраняются после перезагрузки в том же браузере и учитываются поиском, фильтрами, сортировкой, пагинацией и корзиной. Удаление товара также убирает его из корзины; изменение цены пересчитывает итог. При отказе хранилища форма показывает ошибку и не применяет несохранённые изменения.

Это локальный CRUD без общего серверного хранилища или авторизации администратора: изменения не передаются другим посетителям и устройствам. Каталог загружается целиком один раз, затем фильтруется и показывается страницами по 12 товаров. Если API недоступен, сохранённые локальные товары остаются доступны. Заказы с созданными или изменёнными товарами оформляются демонстрационно в браузере; остальные используют `/carts/add` DummyJSON.

Для проверки через локальный HTTP-сервер откройте `tests/shop-crud.html`. Проверки используют тестовые ответы API и восстанавливают исходные данные корзины и товаров после завершения. Успешный результат — `PASS: 24 проверок`.
